# Sea Battle

A [Chickadee Bandit](https://chickadeebandit.com/app-library/sea-battle) app.

Async turn-based naval grid game — challenge a family member, place your fleet, and fire away.

## Features

- Challenge any household member.
- Secret fleet placement on a 10×10 grid.
- Turn-by-turn play with push notifications.
- Multiple concurrent games.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-sea-battle/releases/latest/download/bundle.json
```
